PROJECT / 03

三星堆博物馆网页设计

“三星堆博物馆官网”网页设计以提升博物馆文化传播与观展服务体验为目标，通过对三星堆文物、展览内容与用户浏览需求的梳理，提炼神秘、

厚重的古蜀文化气质，采用黑金、青铜绿与米白色为主色，结合文物影像、材质肌理和清晰的模块化布局，构建具有沉浸感的视觉风格，并完

成开放时间、博物馆简介、展览展示、藏馆文物、咨询公告、社会教育及文创精品等页面内容设计，形成集文化展示、信息查询与参观服务于

一体的博物馆官网界面。

PROJECT / 02

陶行知文创品牌形象设计
